# LoL Polymarket — Public Releases

Ce dépôt public héberge les versions macOS signées et notariées de **LoL Polymarket** ainsi que le flux de mise à jour automatique Sparkle (`appcast.xml`).

## 📥 Téléchargement Direct (macOS)
👉 **[Télécharger la dernière version de LoL Polymarket (.zip)](https://github.com/cr0r1/lol-polymarket-releases/releases/latest/download/LoL_Polymarket.zip)**

### Installation :
1. Décompressez `LoL_Polymarket.zip`.
2. Glissez **`LoL Polymarket.app`** dans votre dossier `/Applications`.
3. Les mises à jour suivantes sont téléchargées et installées automatiquement via **Sparkle**.
